# Hero Travel — Travel Agency Landing Page

A responsive, multi-section landing page for a fictional travel agency, built from scratch with **HTML5** and **CSS3**. Designed to showcase clean, modular front-end development with a dedicated stylesheet per page section.

🌐 **Live Demo:** [https://jahidhemel.github.io/Travel-Website/](https://jahidhemel.github.io/Travel-Website/)

---

## ✨ Features

- 🧭 Sticky header with navigation and brand logo
- 🔍 Hero banner with destination, date, and tour-type search panel
- 🌍 Popular tours section with feature highlights
- 🏝️ Destination grid showcasing 7 travel locations
- ⭐ "Why Choose Us" section with three core value propositions
- 💸 Deals & discounts cards for featured packages (Santorini, Bali, Maldives)
- 🎬 Embedded YouTube video section for visual storytelling
- 📬 Newsletter signup form
- 📱 Responsive layout suitable for mobile, tablet, and desktop
- 🎨 Modular CSS — separate stylesheet per UI section
